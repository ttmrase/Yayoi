# Phase 4 の手法検証(director 指示: Q-A)

Phase 4(書き手ごとの追加学習)の手法を、Phase 3 と並行して CPU のバックグラウンドで検証する。**すべて合成データ**(手書き風フォント + 書き手のゆらぎ)。
実際の手書きは同じ書き手でも字形のばらつきがずっと大きいので、ここでの値は楽観側の見積り。実データは使っていない。
順序(director 指示): (0) 天井の見積り → (a) R2(数字専用 CRNN-CTC)の全層学習 → (d) R1 と R2 の一致による確信度 → (b) 入力解像度・前段の学習 → (c) 文脈。

## (0) 天井の見積り: 確定ページ数 N を増やしても頭打ちか(方法の限界か、合成データのノイズか)

**設定**: 書き手 4 人 × 各 212 ページの連続ページ(`wa_big`、摘要は書き手ごとの 60 語から Zipf で繰り返す)。先頭 N ページ(N ∈ {20, 50, 100, 200})の**その書き手のセルだけ**で、
全体の適応済み重みから追加学習(日付・科目・金額 = 幅 256、摘要 = 幅 384、後段 4 ブロック + デコーダ + 出力層、L2-SP 0.1、全体の学習セルの 50% を混ぜて忘却を防ぐ、
ラベルは確定値だけから(`--label-mode resolved`))。続く 12 ページ(未使用)を認識して、出荷の確信度モデルのまま評価。
**Arm A(学習量を固定)**: 1 回の追加学習で見るサンプル数を 4000(のべ)に固定(`--max-passes 4000`)。N を増やすと、同じ更新回数のまま**データの多様さだけ**が増える。

### Arm A の結果(4 人の平均。値の正解率 / 要確認率、空欄を除く。見逃し = 全セル中)

| N | 日付 | 金額 | 日付+金額 | 摘要 | 科目 | 見逃し |
|---|---|---|---|---|---|---|
| 0(全体の重み) | .760 / .94 | .767 / .87 | .763 / .91 | .350 / .91 | .948 / .26 | 0.13% |
| 20 | .812 / .89 | .820 / .82 | .816 / .85 | .666 / .69 | .956 / .25 | 0.23% |
| 50 | .812 / .92 | .817 / .83 | .814 / .88 | .699 / .67 | .954 / .25 | 0.07% |
| 100 | .812 / .89 | .828 / .83 | .820 / .86 | .730 / .65 | .952 / .25 | 0.13% |
| 200 | .813 / .90 | .826 / .83 | .820 / .87 | .742 / .65 | .951 / .26 | 0.13% |

書き手ごとの 日付+金額: N=0 → 200 で .883→.902 / .640→.667 / .730→.844 / .821→.879。追加学習の時間(1 スレッド、幅 256+384 の合計): 約 8〜10 分(学習量が固定なので N によらない)。

**読み取り(Arm A)**: 学習量を固定したまま N を 10 倍(20 → 200)にしても、日付・金額の正解率は 0.816 → 0.820 で**変わらない**。データの多様さを増やすだけでは頭打ち。
摘要は N とともに伸び続ける(.666 → .742)が、書き手が繰り返す語を覚える効果(辞書・メモリでも似た効果)で、字形の学習とは別。
次に、学習量も増やした Arm B(N=200、エポック 3 = 約 40,000 のべ)・前段も学習した Arm C(N=200、全層学習)・筆の崩しが弱い書き手(k=0.5)で、「方法の限界」と「合成データのノイズ」を分ける(実行中)。
