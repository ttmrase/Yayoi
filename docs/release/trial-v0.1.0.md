# yayoi-ocr 試用版 0.1.0(試用版・pre-release)

手書きの経理帳票(A4・1 様式)のスキャン画像や写真を読み取り、**弥生会計(やよいの青色申告 25)に取り込める CSV** を作る Windows 用のアプリの、**試用版**です。
読み取りと学習は、すべてお使いのパソコンの中だけで行い、**アプリ自身はインターネットに接続しません**(画面の表示に使う Microsoft の WebView2 ランタイムの更新などの通信は、アプリとは別です)。

> **試用版です。** 読み取り結果には間違いが混ざります。アプリが「要確認」とした項目は、必ず目で確かめてください。確定した値だけが CSV になります。
> 弥生への取り込みは元に戻せません。**取り込む前に、弥生側でバックアップを取ってください。**

## 中身について

- 認識モデルは、**NDLOCR-Lite の学習済みモデルを元に、合成データ(架空の帳票)で追加学習したもの**です。**利用者の帳票データは、一切含まれていません**。
- この zip は、**GitHub Actions で、ソースコードから自動でビルド**したものです(ビルドの記録と、重みの出所〔実際に作った重みの SHA256・合成データの要約〕は、zip に入っている `model_provenance.md` にあります)。
  ビルドの中で、この zip そのものを Windows の環境で、展開 → 導入(`setup.ps1`)→ 起動 → 取り込み・認識・確定・CSV の出力 → バックアップ・復元 → アンインストール、まで自動で試験しています。
- ビルドのあとに、学習にも較正にも一度も使っていない**合成の評価ページ 200 ページ**で、この zip の重みの質を確かめています(合格の基準: 要確認とされずに間違えた割合が、全体で 0.5% 以下、列ごとに 日付・科目・摘要 0.5% 以下・金額 0.1% 以下)。
  結果は、適応済みの重みで、要確認とされずに間違えた割合が全体で約 0.19%、最も高い列(科目)でも約 0.33%、金額の列は 0 件でした。**合成データでの数値であり、実際の手書き帳票での精度を示すものではありません。**
- あなたの帳票の画像・確定した値・学習した結果は、すべてお使いのパソコンの `%LOCALAPPDATA%\yayoi-ocr` にだけ保存され、外へは送られません。
- アプリ自身は、実行時にネットワークを使いません(WebView2 ランタイムなど Microsoft のコンポーネントの通信は、アプリでは制御できません)。
- 「学習」画面の「精度レポートを保存」は、**任意**です。確定したページ数や要確認の割合などの**統計だけ**のファイルを作ります(帳票の内容は含みません。送る前にメモ帳で中身を確かめられます)。

## 導入のしかた(要点)

1. zip を展開します。
2. PowerShell で、展開したフォルダから次を実行します(導入は完全オフラインです)。

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup.ps1
   ```

3. デスクトップに作られた **yayoi-ocr** のショートカットから起動します。
4. 初回起動の「初期設定」で、支払手段・ページのタイトル・税区分などを入れます(弥生の登録名と**一字一句同じ**にしてください)。

詳しい手順・キー操作・困ったときの対処は、zip に入っている **`manual.html`**(ブラウザで開きます)をご覧ください。アンインストールは、zip に入っている `uninstall.ps1` で行えます。

## 動作環境

- Windows 10(version 1803 以降)/ Windows 11、64 ビット
- **CPU 版**です(GPU は使いません)。1 ページの読み取りに、10〜30 秒ほどかかる見込みです(目安です。Windows の実機では未測定です)
- 空き容量 約 3 GB
- WebView2 ランタイム(Windows 11 は標準で入っています。Windows 10 で無い場合は、Microsoft の「Evergreen Standalone Installer」(x64)を入れてください)
- 弥生:やよいの青色申告 25(デスクトップ版)

## 既知の制限と、実機で未確認の項目

- **認識モデルの調整は合成データだけで行いました。実際の手書き帳票での精度は、まだ測っていません。** 使いながら、確定したページから、書き手の字形に合わせて少しずつ学習します(学習は 1 つの共通のモデルで行います)。
- **Windows の実機での確認は、これからです。** 自動試験(Windows のサーバ環境)は通していますが、次の項目は、実際の PC・実際の操作では未確認です: 日本語入力(IME)での操作、高解像度ディスプレイでの表示、WebView2 での「名前を付けて保存」、読み取りの実際の速度、弥生への実際の取り込み。
- **署名がありません。** 同梱の Python などに電子署名がないため、Windows の SmartScreen やウイルス対策ソフトが警告を出すことがあります。上の SHA256 が一致することを確かめたうえで、許可してください。
- アプリは、保存するデータを**暗号化しません**。BitLocker などのディスク暗号化をおすすめします。バックアップの zip には、帳票の内容が含まれます。保管と持ち運びにご注意ください。
- 「学習」画面の追加学習は、確定したページがたまってから動きます。学習した世代の採用は、見逃しが増えないことを確かめたうえで行い、悪化したときは自動で前の世代に戻します。
