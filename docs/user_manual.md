# yayoi-ocr ご利用の手引き(試用版)

手書きの経理帳票(A4・1 様式)のスキャン画像や写真を読み取り、**弥生会計に取り込める CSV** を作るアプリです。
インターネットにはつながりません(読み取りも学習も、すべてこのパソコンの中だけで行います)。

> **大事なこと**: 読み取り結果には間違いが混ざります。アプリが「要確認」とした項目は、必ず目で確かめてください。確定した値だけが CSV になります。

## 1. 最初の準備(初回だけ)

1. デスクトップの **yayoi-ocr** を開きます。黒い小さな画面(コンソール)が最小化されて動いています。**閉じるとアプリも終わります**。
2. 最初に「初期設定」の画面が出ます。次の 3 つを入れます。
   - **支払手段**: 帳票の「科目」欄に書く名前(例: 現金)と、弥生の貸方の科目名。
   - **タイトル**: 帳票の上に書く勘定科目名(例: 旅費交通費)と、弥生の借方の科目名。
   - **事業者区分・課税方式・経理方式**: 弥生の設定に合わせます。
3. 科目の名前は、**弥生に登録した名前と一字一句同じ**にします(違うと、弥生が取り込みのときに「マッチングリスト」を出します)。
4. あとから変えるときは「設定」の画面で変更し、「保存」を押します。

## 2. 帳票を取り込む(「ジョブ」)

1. 「ジョブ」の画面で、PDF や画像(JPEG・PNG・TIFF)をウィンドウにドラッグするか、ファイルを選びます。複数まとめて選べます。
2. 「ジョブ名」は自由です(月ごとなど)。
3. 読み取りが始まります。最初の 1 ページができたら、「確認待ち」になり、確認を始められます(残りのページは、確認している間に読み取ります)。1 ページあたり、パソコンによって 10〜30 秒ほどかかります。
4. 読み取りに失敗したページは、確認の画面で「読み取りに失敗しました」と出ます。そこにあるボタンで、もう一度読み取れます。

## 3. 読み取り結果を確認する(「確認」)

画面には、帳票の 1 行ごとに 4 つの欄(日付・科目・摘要・金額)と、切り出した元の画像が並びます。

- **色のついた(要確認の)欄**を、上から順に見ます。画像と入力済みの文字を見比べて、合っていれば **Enter**、違っていれば直してから **Enter** を押します。
- 要確認でない欄も、念のため目を通してください。
- 「〃」(同上)や年の省略は、自動で補ってあります(「展開済み」と表示されます)。もとの欄を直すと、それを参照する欄も直ります。

### キー操作

| 操作 | キー |
|---|---|
| 確認して次へ | **Enter** |
| 前の欄へ戻る | Shift + Enter |
| 上下の行へ | ↑ ↓ |
| 候補から選ぶ(欄の下に候補が出ます) | **Alt + 数字**(Alt+1 が一番上の候補) |
| 入力を元に戻す(その欄) | Esc |
| 操作の取り消し・やり直し | Ctrl + Z / Ctrl + Y |
| 次の未確認の要確認欄へ | Ctrl + ↓(戻るのは Ctrl + ↑) |
| 行ごとの表示 ↔ 列ごとの表示 | Ctrl + L |
| この行の税区分を選ぶ | F2 |
| このページを確定する | Ctrl + Enter |

- 日本語を入力しているとき(変換中)の Enter は、変換の確定です。次の欄へは進みません。もう一度 Enter を押してください。
- 要確認の欄は、画像を少しの間見てからでないと Enter が効きません(うっかり連打して飛ばさないためです)。
- **金額の末尾が「-」か数字か分からない欄**(例: 500 か 5000 か)は、**Alt + 1 / Alt + 2 で選ぶまで**先へ進めません。
- 学習画面で「**提案モード**」と出ているときは、金額が「使用中の世代」と「提案の世代」で違う欄も、同じように**選ぶか入力するまで**進めません。

### ページのタイトルと税区分

- ページの上に書かれた勘定科目名(タイトル)を確認します。弥生の借方科目は、これから決まります。
- 税区分は、科目ごとの設定が使われます。行ごとに変えたいときは **F2**。同じ摘要で前に選んだ税区分は、次から「提案」として出ます(設定の画面で編集・削除できます)。

### ページを確定する

すべての要確認の欄を確認すると、「確定」できます(Ctrl + Enter)。確定していないページは、CSV にできません。
確定した内容は、次のページの読み取りに使われます(よく書く摘要・科目・金額を覚えていきます)。

## 4. CSV を作って弥生に取り込む(「出力」)

1. 「出力」の画面で、出力したい(確定済みの)ページを選びます。
2. 形式は、通常は「**弥生インポート形式**」(仕訳日記帳へのインポート)です。
3. 画面の「検証」で、足りない設定や、取り込めない文字・日付などがあると理由が出ます。直してから出力します。
4. 前に出力したのと同じ行を、もう一度出力しようとすると、警告が出ます(弥生は同じデータを警告なしで二重に登録するためです)。
5. 「ダウンロード」で保存先を選んで、CSV を保存します。
6. **弥生に取り込む前に、弥生側でバックアップを取ってください**(取り込みは元に戻せません)。取り込みは弥生の「インポート」で行い、**Excel で開いて保存し直さないでください**(文字化けや形式の崩れの原因になります)。
7. 会計期間の外の日付は、弥生が取り込めません。

## 5. 「学習」画面の見方

このアプリは、確定したページから、あなたの書き方に合わせて少しずつ賢くなります。

- **確定したページ・要確認の割合・直した割合・1 ページの確認時間**: 使うほど、直す割合が減るのが目安です。
- **追加学習**: 確定したページがたまると、裏で自動で学習します(学習中も確認の作業はできます)。「今すぐ学習する」でも始められます。数分〜十数分かかります。
  - 学習した新しい「世代」は、確定済みのページの一部で試し、**見逃しが増えず、正解率が下がらない**ときだけ採用します。採用されなかったときは、理由が表示されます。
  - 確定したページが少ないうちは、採用されにくくなっています(安全のためです)。
- **提案モード**: 「見逃しの基準には届かないが、正解率は明らかに高い」世代は、**入力済みの値の提案**だけに使います。「提案モードで使用中」と表示されます。
  - 要確認かどうかの判定は変わりません(親の世代で見逃しにならなかった欄だけが、確認なしになります)。値が親と違う欄は、必ず要確認になります。
  - 処理の遅いパソコンでは、追加学習の欄の「**提案モードを使う**」をオフにできます(読み取りの時間が約 1.4 倍になるのを避けられます)。
- **安全のための自動停止**: 採用した世代で読み取ったページで、「要確認でなかったのに直した」欄(特に金額)が見つかると、安全のためその世代を自動で止め、前の世代に戻します。画面の上に通知が出ます。「確認した」で消えます。
- **使えない世代**: 世代のファイルが壊れていると、出荷時の状態に戻して読み取りを続けます。画面の上に通知が出ます。
- **世代を戻す**: 一覧の「この世代に戻す」で、過去の世代に戻せます。「リセット」は、出荷時の状態に戻します(切り出し画像などの学習データを残すか消すかを選べます)。
- **精度レポート**: 件数・割合だけの統計ファイルです。帳票の内容(日付・科目・摘要・金額・タイトル・ファイル名)は含まれません。中身は、メモ帳で確かめてから送れます。

## 6. バックアップと復元(「設定」の一番下)

- **バックアップを作成**: 確定した値・切り出し画像・学習した世代・設定・税区分の記憶を、1 つの zip にまとめます。「保存する」で、保存先(USB メモリや別のドライブなど)を選びます。
  - 「取り込んだ元画像も含める」を選ぶと大きくなります。含めないと、確定する前のページの読み取りのやり直しはできません。
  - **バックアップには、帳票の内容が含まれます。保管と持ち運びにご注意ください。**
- **バックアップから復元**: zip を選ぶと、中身を検査して、日時・ページ数などを見せます。「置き換える」を選ぶと準備をして、**アプリを閉じて開き直したとき**に、いまのデータがバックアップの内容に置き換わります。
  - いまのデータは自動で退避されます。結果に問題がなければ、「退避したデータを削除」で容量を空けられます。
  - 読み取りや学習の最中は、復元の準備はできません。
  - このアプリで作ったもの以外の zip、壊れた zip、書き換えられた zip は、理由を表示して断ります。

## 7. データの保管と削除

- データは `%LOCALAPPDATA%\yayoi-ocr`(エクスプローラーのアドレス欄に貼ると開きます)に保存されます。取り込んだ画像・切り出し画像・確定した値・出力した CSV が入ります。
- **アプリはデータを暗号化しません。BitLocker などのディスク暗号化をおすすめします**(紛失・盗難に備えるため)。共有のパソコンでは、専用のアカウントで使ってください。
- 「設定」の「元画像の保管」で、出力のあとに元の画像を自動で削除できます。
- 「学習」の「リセット」で、切り出し画像(学習データ)を消せます。
- アンインストールとデータの削除は、手引きの最後(「9. アンインストールとデータの削除」)を見てください。

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| アプリが開かない・白い画面 | 「WebView2 ランタイム」が必要です(Windows 11 には標準で入っています)。Windows 10 で入っていなければ、Microsoft の「Evergreen Standalone Installer」(x64)を入れてください。 |
| 黒い画面にエラーが出ている | その内容(日本語の文章やコード)を控えて、開発者に伝えてください。 |
| 読み取りがとても遅い | 追加学習の最中は遅くなります(終わるまで待つか、学習画面から止めます)。それでも遅いときは、「提案モードを使う」をオフにしてください。 |
| 読み取りに失敗したページがある | 確認の画面のボタンで、もう一度読み取ります。何度も失敗するときは、画像の向き・明るさ・解像度(300dpi 程度)を確認してください。 |
| 表の枠(罫線)がずれている | 確認の画面の「罫線を確認」を開き、青い線がずれていたら、表を囲む 4 つの丸をドラッグして直し、「切り直す」を押します。合っているときは「境界は合っている」を押します。 |
| 「世代 N が使えません」と通知が出た | 出荷時の状態に戻して動いています。学習画面で理由を確かめ、「確認した」を押してください。 |
| 弥生で「マッチングリスト」が出た | 設定の科目名・税区分が、弥生の登録名と違います。設定を直して出力し直してください。 |
| その他 | ログ(`%LOCALAPPDATA%\yayoi-ocr\logs\app.log`)の中身を開発者に送れます。**ログには、帳票の内容(値・ファイル名)は書かれません**(ID・件数・コードだけです)。30 日を過ぎたものは自動で消えます。 |

## 9. アンインストールとデータの削除

1. アプリを終了します(黒い小さな画面も閉じます)。
2. セットアップに使ったフォルダ(`setup.ps1` のあるフォルダ)から、次を実行します:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
   ```

   - 既定では、**プログラム(Python・部品・認識の重み・ショートカット)だけを削除し、データは残します**。
   - データ(取り込んだ画像・確定した値・学習した世代・出力・バックアップの一時ファイル・ログ)も消すときは、`-DeleteData` を付けます。確認のために「DELETE」と入力する必要があります:

     ```powershell
     powershell -ExecutionPolicy Bypass -File .\uninstall.ps1 -DeleteData
     ```

3. データを消す前に、必要なら「バックアップを作成」で保存してください。
4. **通常のファイル削除は、ディスクの内容を完全には消しません。** 廃棄・譲渡の前は、ディスクの暗号化(BitLocker)を有効にしておくか、`cipher /w:C:\` などで空き領域を消去してください。
5. 「バックアップ」で保存した zip、弥生に渡した CSV、持ち出した「精度レポート」は、アンインストールでは消えません。それぞれ手で削除してください。
