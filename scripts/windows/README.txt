yayoi-ocr 試用版

1. この zip を展開し、そのフォルダで次を実行します(右クリック → 「PowerShell で実行」ではなく、下のコマンドを使ってください)。
       powershell -ExecutionPolicy Bypass -File .\setup.ps1
2. 完了後、デスクトップの「yayoi-ocr」から起動します。
3. 初回起動では「初期設定」が出ます(支払手段・ページのタイトル・税区分)。あとで「設定」画面で変えられます。
4. 手書き帳票の PDF・画像を取り込み、認識結果を確認して確定し、「出力」から弥生用の CSV を保存します。

【弥生に取り込むときの注意】
- 出力した CSV は Excel で開かず、弥生(やよいの青色申告 25)で直接取り込んでください。
- 弥生のインポートは元に戻せません。取り込む前に、弥生でバックアップを取ってください。
- 科目・補助科目・税区分の名前は、弥生の登録名と完全に一致させてください。
- 同じデータを二度取り込むと、弥生は警告なしで重複登録します(このアプリは出力した行を記録し、再出力のときに警告します)。

【データの扱い】
- 取り込んだ画像・確定した値・出力した CSV は %LOCALAPPDATA%\yayoi-ocr に保存されます。ディスクの暗号化(BitLocker)を推奨します。
- アプリは実行時にネットワークを使いません。
- 「学習」画面の「精度レポートを保存」は、件数と割合だけのファイルを作ります(帳票の内容は含まれません)。開発者に送れます。

詳しい手順は windows_setup.md、動作確認の項目は windows_checklist.md を見てください。
